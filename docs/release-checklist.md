# 寻达 Agent 工作台发布检查表

日期：2026-08-06

## 已通过

- `npm run test:release`：109 项全量测试通过；75 项集成测试通过。
- 字段库：V1 由真实蒲公英响应生成 379 个能力项，兼容字段层展开为 421 个蒲公英字段变体；62 个能力项已与蒲公英前端名称和路径对齐，317 个仅观察到接口、等待前端校准。合作/日常、图文/视频/图文+视频、30/90 天、全流量/仅自然流量均以完整名称呈现，模糊任务不会默认视频。
- 字段合同：合作 90 天全流量、合作 90 天仅自然流、日常 30 天和近 16 篇可同时存在。
- 内容类型：图文、视频和图文+视频进入字段唯一键，不再由品牌模板暗中默认。
- Excel：真实美德乐测试表识别 3 位达人和 30 个蒲公英字段，按表头生成 2 类动态口径组；便携式 OpenPyXL 链路离线回填 90 个单元格、保留 26 个证据不足或人工字段空白，9 个公式的错误扫描为 0；字段模板可与对话中另贴的链接合并，固化模板也可把选定字段追加到仅含链接的 Excel。
- 状态机：未澄清不能确认，未确认不能采集，口径版本变化使旧检查点失效。
- 输出策略：蒲公英值、公式、模型证据字段和人工业务字段使用独立策略；授权等事实字段保持空白。
- 账号：生产式隔离实例验证未登录返回 401，管理员 Cookie 会话可恢复，管理员可创建/停用账号，媒介访问管理员接口返回 403。
- 连接：个人中心的蒲公英登录画面可显示、点击并在刷新后恢复；加密 storageState 可在服务重启后恢复并在采集前验活；管理员可显式共享给指定角色，个人连接优先且媒介无权读取或管理共享连接；无连接任务进入 `NEEDS_ATTENTION`，不会被误报为一般程序失败。
- 留存：任务列表只显示最近 7 天；清理器只删除到期任务；任务支持独立复制、提前删除，并可从已完成的动态任务固化字段模板。
- 安全：密码 scrypt 哈希、会话只存 token 哈希、蒲公英 storageState AES-GCM 加密且解密内容不落任务明文、启动迁移清理旧版明文临时状态、敏感埋点字段被删除。
- 管理观测：可查看澄清、字段合同确认、Qwen/DeepSeek 调用、校验失败、采集稳定性和登录态失效聚合数据。
- 模型：Qwen3.7-Max 和 DeepSeek V4-Pro 的真实最小请求均已连通；Qwen 工具调用白名单、DeepSeek 证据约束、超时和失败边界由程序测试覆盖。
- 三层闭环：Excel 未知表头先生成字段库候选，Qwen 只能选择白名单 `capabilityId`；确认和启动均执行字段合同准入；采集结果保存请求签名和值状态；DeepSeek 每个单元格必须引用可反查的证据包，单格失败不会影响蒲公英原始值或同一行其他字段。
- HTTP 冒烟：16 项检查通过，覆盖未登录 401、角色隔离、共享连接管理权限、10 位以上链接导入限制、字段模板与另贴链接合并、模糊字段追问、历史任务固化模板、仅链接 Excel 自动追加字段、连接缺失回到需处理、复制、删除和管理员观测。
- 浏览器：固定左侧导航、独立任务记录、视口内弹性会话、并排字段侧栏、口径整组选入、Excel 附件/移除状态、个人中心重新连接、用户管理和 Agent 运行面板均可访问；页面无横向或纵向 body 溢出，浏览器控制台无错误。
- 部署：`docker compose config --quiet` 通过；安全响应头、PostgreSQL Schema 和环境变量样例已更新。
- 本地交付：临时 SQLite 实例成功监听 `127.0.0.1:18731`，`/healthz` 返回 `ok: true`，首次管理员设置接口返回 `setupRequired: true`、`setupAllowed: true`；仓库提供 `npm run setup:local`、`npm run web:local` 和独立交付指南。
- Git 隐私边界：浏览器资料、蒲公英 Cookie 与连接密文、本机加密密钥、SQLite、任务目录、原始响应、Excel 产物、模型密钥和本机环境变量均已排除，只保留代码、配置样例、测试、部署文件和产品演示素材。

## 发布前必须补做

- 使用当前团队有效的蒲公英账号，在个人中心完成首次连接并保存。
- 用 3 位测试达人执行真实美德乐 Excel 任务；随机抽查至少 1 位达人：
  - 合作笔记 90 天图文+视频全流量曝光/阅读。
  - 合作笔记 90 天图文+视频仅自然流曝光/阅读。
  - 日常笔记 30 天图文+视频全流量指标。
  - 报价、公式和 CPC 依赖。
- 人工核对导出 Excel 的合并单元格、公式、空白原因和推荐理由。
- ECS 环境用真实账号验证个人中心站内登录画面、扫码、验活和加密保存均绑定到当前寻达用户。
